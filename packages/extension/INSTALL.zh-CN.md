# 提示词优化器浏览器扩展：安装与使用

适用于 Chrome、Edge 等基于 Chromium 的浏览器。

## 安装（开发者模式加载已解压的扩展）

1. 把 `goprmpt-extension-<版本号>.zip` **先解压**到一个固定的文件夹，例如 `D:\goprmpt-extension`。
   直接把 zip 拖进扩展页面是装不上的，必须先解压。解压后的文件夹里应该能直接看到 `manifest.json`。
2. 打开扩展管理页：Chrome 地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`。
3. 打开右上角（Edge 在左下角）的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择第 1 步解压出来的文件夹。
5. 扩展列表里出现“提示词优化器”即安装成功。建议点浏览器工具栏的拼图图标，把它固定到工具栏。

注意：解压出来的文件夹不要删除或移动，浏览器每次启动都从这里加载扩展。升级时用新版本的文件覆盖该文件夹，再在扩展页点击扩展卡片上的刷新按钮。

## 使用

- **优化网页上的文字**：在任意网页选中一段文字，右键选择 **用提示词优化器优化“…”**。会在新标签页打开提示词优化器，选中的文字已经填在“用户提示词”优化的输入框里，选好模型后点击优化即可。
- **直接打开**：在网页空白处右键选择 **打开提示词优化器**，或者点击工具栏上的扩展图标。

第一次使用前，需要在提示词优化器的“模型管理”里填好自己的 API 密钥。所有数据都保存在本机浏览器里。
