# 高词（GoPrmpt）完整使用手册

这本手册面向所有日常使用者。不需要懂编程，照着步骤和配图，5 分钟就能上手官网、全屏工作台、浏览器右侧栏插件和账号云同步。

## 1. 先搞懂高词能帮你做什么

很多人用 AI 时会遇到同一个问题，心里想得很清楚，敲进去一两句话，模型却回复一堆空话或跑偏的内容。高词做的事情很直接，把你的口语想法改写成结构清楚、有约束、结果稳定的专业提示词，并且让你在同一屏里对比改写前后的真实效果。

高词由三个配合使用的部分组成。

1. **官网内容库（https://goprmpt.com）**：提供 151 条中英双语现成提示词、26 节系统课程和浏览器插件安装包。
2. **全屏优化工作台（https://goprmpt.net）**：负责改写提示词、多轮迭代、并排测试对比和保存个人收藏。
3. **浏览器右侧栏插件（Chrome / Edge）**：不用离开 DeepSeek、ChatGPT 或任意网页，在浏览器右侧滑出紧凑工作台随时改写，还能和网站双向同步数据。

![高词官网首页与 3 秒看懂优化效果](./images/01-home-hero.png)

> 图中重点：顶栏可直接进入**工作台**、**提示词库**、**教程与写法**、**浏览器插件**和**使用手册**；右侧「3 秒看懂优化效果」卡片支持切换周报、小红书、代码评审、AI 绘图 4 个真实案例；点击右上角可切换浅色或深色主题与中英文界面。

## 2. 5 分钟快速上手（免登录直接用）

高词支持不注册、不登录直接使用。你只需要完成一次模型配置，以后打开网页就能立刻优化提示词。

### 2.1 第一次使用前配置模型（自带密钥说明）

高词采用本地自带密钥模式（BYOK）。你填入的 API Key 只保存在你自己的电脑浏览器里，请求由浏览器直接发往你选的模型厂商，高词服务器看不到也不会保存你的 API Key。

操作步骤如下。

1. 打开工作台 https://goprmpt.net 。
2. 在左侧边栏点击 **模型管理**。
3. 在弹出的窗口顶部选择 **文本模型**（写图提示词时选 **图像模型**）。
4. 找到你已有账号的模型厂商（例如 DeepSeek、DashScope 通义千问、Google Gemini、Anthropic、MiniMax），点击该行右侧的 **编辑**。
5. 填入你的 API Key 并保存，点击 **测试连接** 确认提示成功，最后点击 **启用**。

![工作台模型管理配置窗口](./images/06-workbench-model-manager.png)

> 图中重点：左侧栏点 **模型管理** 会打开此窗口。每个厂商行右侧都有 **测试连接**、**编辑**、**克隆** 和 **启用** 四个按钮；如果你用的是自定义接口或本地模型（如 Ollama），点击右上角 **添加** 手动填写接口地址即可。

### 2.2 认识全屏工作台界面

配置好模型后，回到工作台主界面。整个屏幕从左到右分为三个区域。

![高词全屏工作台界面布局](./images/05-workbench-overview.png)

> 图中重点：
> - **最左侧暖石边栏**：上方是 **收藏夹**、**功能提示词**、**历史记录**、**模型管理**、**数据管理**、**变量管理**；左下角依次是 **日间/夜间** 切换、**登录 / 云同步** 和语言切换。点击品牌旁边的折页图标可以把边栏收窄成图标条。
> - **顶部模式栏**：在 **基础**（系统提示词 / 用户提示词）、**上下文**、**图像** 和 **竞技场** 之间切换；右侧可直达 **151 条词库** 和 **26 节教程**。
> - **中间编辑区与右侧对比区**：中间上方输入 **原始提示词**，选好 **优化模型** 和 **优化提示词** 后点绿色 **优化** 按钮，改写结果会出现在 **优化工作区**；右侧 A/B 两栏可以同时跑「原始提示词」和「优化工作区」，一眼看出改写到底有没有变好。

## 3. 官网 151 条词库与 26 节课程怎么用

### 3.1 直接套用 151 条现成提示词

如果你不想从零写起，直接打开 https://goprmpt.com/library/ 。

1. 用顶部搜索框输入关键词（例如「周报」「小红书」「海报」），或点击分类标签筛选（10 个文本分类 + 8 个视觉绘图分类）。
2. 点击任意一条卡片，右侧会滑出详情抽屉，列出这条提示词需要填写的变量。
3. 把你的具体信息填进变量输入框，页面会自动拼出完整提示词。
4. 想立刻发给大模型，点击绿色 **复制提示词**；想继续按自己的风格改写，点击 **在优化器中使用**，或点 **复制导入码** 到工作台里导入。

![提示词库中的周报生成器详情与变量填写表单](./images/02-library-weekly-report.png)

> 图中重点：右侧抽屉顶部会给出变量说明表（`{{记录}}`、`{{汇报对象}}`、`{{字数上限}}`）。把零散记录贴进输入框，点底部 **复制提示词** 就能拿到填好变量的成品指令。注意底部提示，点击 **在优化器中使用** 会按导入码把模板原文带进工作台，临时填在网页里的变量值不会带过去。

### 3.2 跟着 26 节双语教程系统入门

打开 https://goprmpt.com/learn/ 可以按两条轨道学习。

- **入门课程（14 课）**：适合刚接触 AI 的同学，从「一条提示词由哪四块组成」讲到角色、背景、示例和迭代。
- **进阶写法（12 课）**：适合经常觉得模型听不懂人话的人，专门讲变量槽位、固定骨架、负面清单和防编造约束。

![教程页第 1 课的改写前后对比与课后练习](./images/03-learn-course.png)

> 图中重点：每节课都配有左右对照的 **改写前** 与 **改写后** 真实案例，以及一块 **练习** 任务卡。点击练习卡左下角的 **去优化器里试试**，可以直接跳到工作台动手练。

## 4. 浏览器右侧栏插件安装与用法

很多时候你正在 DeepSeek、ChatGPT、Claude 或豆包网页里聊天，来回切换高词网页会打断思路。装上高词浏览器插件后，工作台会贴合在浏览器右侧边栏里，左边对话、右边改写提示词。

### 4.1 30 秒本地安装（Chrome / Edge 通用）

1. 打开 https://goprmpt.com/#extension ，点击绿色 **下载浏览器插件 (.zip)** 按钮，把 `goprmpt-extension-2.16.0.zip` 保存到电脑。
2. 在 Chrome 地址栏输入 `chrome://extensions`（Edge 输入 `edge://extensions`）并回车。
3. 打开页面右上角的 **开发者模式** 开关。
4. 把下载好的 `goprmpt-extension-2.16.0.zip` 直接拖进扩展管理页面（也可以先解压再点 **加载已解压的扩展程序** 选择解压后的目录）。
5. 点击浏览器右上角拼图图标，把 **高词 · GoPrmpt** 的翡翠绿 `G` 图标固定到工具栏。

![官网浏览器插件介绍、下载按钮与 30 秒本地安装指南](./images/04-home-extension-download.png)

> 图中重点：直接下载无需访问海外扩展商店。Edge 与 Chrome 114 及以上版本均可直接拖入安装。

### 4.2 插件的三种顺手用法

1. **点击工具栏图标打开右侧边栏**：在任意网页点击右上角翡翠绿 `G` 图标，右侧会滑出紧凑单栏工作台。
2. **划词右键直接优化**：在网页上选中一段草稿或问题，点击鼠标右键，选择 **用高词 · GoPrmpt 在右侧栏优化“...”**，文字会自动带入右侧栏输入框。
3. **右键切换全屏**：想做多模型大屏对比时，在工具栏图标或网页空白处点右键，选择 **在新标签页全屏打开高词 · GoPrmpt**。

![浏览器右侧栏紧凑模式与底部功能菜单](./images/07-sidepanel-compact.png)

> 图中重点：在 420px 左右宽度的右侧栏里，界面会自动切换为单栏紧凑模式。点击左上角 **功能** 按钮即可呼出底部菜单，里面集成了 **收藏夹**、**历史记录**、**功能提示词**、**模型管理**、**变量管理**、**数据管理**，以及最下方的 **登录 / 云同步**、主题与语言切换。

## 5. 账号、双向云同步与邮箱找回密码

如果你只在单台电脑上用，可以一直免登录使用。如果需要在公司电脑、家里电脑和浏览器插件之间共享收藏夹、历史记录、自定义模板与变量，可以注册一个高词账号。

### 5.1 注册账号与绑定邮箱

1. 在工作台左侧边栏底部（或插件 **功能** 菜单底部）点击 **登录 / 云同步**，面板会直接在原位展开，不会弹遮罩窗口。
2. 切到 **注册** 标签页。
3. 输入 3 到 32 位用户名（支持小写字母、数字、下划线、点或短横线）。
4. 建议填写 **邮箱（选填，便于后续找回密码）**。绑定后，既可以用邮箱登录，忘密码时也可以自助收验证码重置。
5. 设置至少 8 位密码并确认，点击 **注册并登录**。

### 5.2 在网站与插件之间双向同步

1. 在 https://goprmpt.net 整理好收藏或模板后，展开左侧 **登录 / 云同步**，点击 **上传到云端**。面板会提示最新版本号（例如 `v2`）并说明模型 API Key 未上传。
2. 打开浏览器右侧栏插件，点左上角 **功能**，再点底部的 **登录 / 云同步**，用同一个账号登录。
3. 点击 **从云端拉取合并**，网站上的收藏、历史、模板和变量会合并进插件，且不会覆盖你本地已配好的模型 API Key。
4. 当另一台设备已经上传过更新版本时，直接上传会触发版本冲突保护，先点一次 **从云端拉取合并** 再上传即可。

### 5.3 修改邮箱、改密码与忘记密码找回

- **已登录状态下绑定邮箱或改密码**：展开云同步面板，点击 **邮箱与修改密码**，在展开的小区域里直接保存邮箱或输入当前密码更新新密码。
- **忘记密码自助重置**：在未登录状态的 **登录** 标签页底部点击 **忘记密码？用邮箱重置**，输入已绑定邮箱并点 **发验证码**；去邮箱查收 6 位数字验证码（15 分钟有效，如果收件箱没看到请检查垃圾箱），填入验证码和新密码后点 **确认重置密码** 即可立即生效。

## 6. 五个真实操作案例（照着做一遍就会）

下面五个案例全部使用高词线上真实模板和功能。建议你直接打开网站跟着做一遍。

### 案例一：用「周报生成器」把 5 句流水账变成老板爱看的周报

**场景**：周五下午 5 点，你手里只有几句零散备忘，想在 2 分钟内写出一份不注水的周报。

**操作步骤**：
1. 打开 https://goprmpt.com/library/?id=weekly-report （参考第 3.1 节配图）。
2. 在 **汇报对象** 保持默认「直属上级」，**字数上限** 保持「400」。
3. 在 **记录** 框里贴入本周零散事项，例如下面这段内容。

```prompt
- 周一修完了官网课程标题重复的显示问题
- 周二上线了用户登录和云同步，目前跑通测试
- 周四给浏览器插件做了右侧边栏模式，周五打包放到官网下载
- 下周准备完善常见问题和实战教程
- 还没拿到设计部的活动宣传图
```

4. 点击 **复制提示词**，粘贴到你常用的大模型对话框发送（或直接点 **在优化器中使用** 在工作台右侧测试框运行）。

**你会看到的结果**：模型严格按「一句话总结 / 本周完成 / 进行中 / 下周计划 / 需要协助」五段输出，没有「圆满完成」「大力推进」这类空话，并自动把「设计部活动宣传图」放进「需要协助」。

### 案例二：在工作台把模糊需求改写成高精度指令并做 A/B 对比

**场景**：你要写一份新品推广文案，但自己脑子里只有一句很模糊的想法。

**操作步骤**：
1. 打开 https://goprmpt.net/#/basic/user （参考第 2.2 节配图）。
2. 在 **原始提示词** 框里输入下面这句话。

```prompt
帮我写一段推销智能保温杯的朋友圈文案
```

3. 选好已启用的 **优化模型**，在 **优化提示词** 下拉框选「专业优化」，点击绿色 **优化** 按钮。
4. 几秒后，**优化工作区** 会生成补全了目标受众、核心痛点、字数范围和禁止夸张用语的完整指令。
5. 看屏幕右侧的测试对比区：在 **A 原始提示词** 和 **B 优化工作区** 选好同一个测试模型，点右上角 **测试全部**。
6. 对比左右两列生成的真实文案。如果觉得语气太正式，点击优化工作区工具栏的继续迭代按钮，输入「改成朋友聊天口吻，控制在 120 字内」再次微调。
7. 满意后点击优化工作区右上角的星形 **收藏** 按钮，下次直接从左侧 **收藏夹** 复用。

### 案例三：用「代码审查」模板做上线前自查

**场景**：开发提交代码前，想让 AI 只查真正的 Bug、空指针和安全漏洞，不要对空格和命名风格说教。

**操作步骤**：
1. 打开 https://goprmpt.com/library/?id=code-review 。
2. 在 **语言** 框填入你使用的技术栈（例如 `TypeScript / Vue 3`），在 **关注点** 框填入 `权限校验、空值处理和竞态条件`。
3. 在 **代码** 框贴入本次修改的函数或代码改动片段。
4. 点击 **复制提示词** 并交给你选定的推理模型运行。

**为什么有效**：这条模板强制模型按「高 / 中 / 低」严重程度排序，每条必须写清位置、触发条件和修改代码；上下文不足时必须列为「需要确认的假设」而不是胡乱猜测，没有问题时必须直接说明而不是硬凑意见。

### 案例四：用图像工作区 +「中文大字排版海报」做活动主图提示词

**场景**：要给公司读书会做一张竖版 3:4 中文海报，直接写「画一张读书节海报」往往会被 AI 画成花哨廉价的网图且汉字乱码。

**操作步骤**：
1. 打开 https://goprmpt.com/library/?id=chinese-typography-poster ，填入变量：**主题** 写 `冬季技术共读会`，**主标题** 写 `共读`，**辅助信息** 写 `12.06 晚 8 点 · 线上直播`，**主色** 写 `深青绿`。
2. 如需针对具体绘图模型（例如即梦、可灵、Midjourney、Gemini 绘图）继续精调，打开 https://goprmpt.net/#/image/text2image ，点击顶部 **图像 → 文生图**。
3. 把提示词贴进 **原始提示词**，还可以点击输入框上方的 **灵感**、**复刻** 或 **风格学习** 辅助工具调整画风与构图。
4. 点击 **优化** 生成最终绘图指令，复制去生图模型出图。

![高词 AI 图像提示词工作区（文生图模式）](./images/08-workbench-image-mode.png)

> 图中重点：切换到顶部 **图像** 标签后，可细分 **文生图**、**图生图**、**多图生图**；左侧上方提供 **灵感**、**复刻**、**风格学习** 三个快捷入口，右侧配有 **变量** 面板和图像生成对比槽。

### 案例五：边聊 DeepSeek 边用右侧栏插件改写并同步回网站

**场景**：你在 DeepSeek 网页聊天时，想把一段复杂的业务需求拆成清晰提示词，并且把这套好用的提示词存起来明天在公司电脑接着用。

**操作步骤**：
1. 在 DeepSeek 网页里，点击浏览器右上角固定的翡翠绿 `G` 图标，右侧滑出高词紧凑边栏。
2. 如果你已在网页上写了一段草稿，直接鼠标选中它，右键点击 **用高词 · GoPrmpt 在右侧栏优化“...”**。
3. 在右侧栏点 **优化**，生成结果后一键复制，直接粘贴到左边的 DeepSeek 对话框发送。
4. 点星号把这条满意的提示词存入插件收藏夹。
5. 点右侧栏左上角 **功能**，展开底部 **登录 / 云同步**，点 **上传到云端**。第二天在任意电脑打开 https://goprmpt.net ，登录后点 **从云端拉取合并**，这条收藏就会完整出现。

## 7. 常见问题排查（FAQ）

| 现象 | 常见原因 | 解决方法 |
| --- | --- | --- |
| 点击「优化」没反应或提示未选择模型 | 还没启用任何文本/图像模型 | 点左侧 **模型管理**，编辑一个厂商填入 API Key，点 **测试连接** 并 **启用** |
| 官网下载的插件拖进 Edge 提示无法加载 | 没开开发者模式，或拖入了旧版缓存包 | 先打开 `edge://extensions` 右上角 **开发者模式**，确认下载的是官网最新的 `goprmpt-extension-2.16.0.zip` |
| 点插件图标还是新开了整页，没在右边弹出 | 浏览器里残留了旧版本插件 | 在扩展管理页先点 **删除** 去掉旧版，再重新拖入新包即可生效 |
| 收不到忘记密码验证码邮件 | 填的邮箱未绑定账号，或被拦截进垃圾箱 | 先查垃圾箱或广告邮件夹，确认使用的是注册或绑定的邮箱地址 |
| 云同步上传提示「云端已有更新版本」 | 另一台设备或插件刚上传过新数据 | 先点一次 **从云端拉取合并**，确认合并无误后再点 **上传到云端** |
